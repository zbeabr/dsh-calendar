1. 修掉重叠：木板右侧的日历标签、黄铜删除钮、穿孔现在分占三段，互不压住。
2. 主屏换成老式终端屏：墨绿磷光底、等宽字体、荧光绿「液晶管」辉光、CRT 扫描线与玻璃斜反光；「挂上」按钮原样保留。
3. 系统提示另起一块细长小液晶屏：输入框下方独立的 SYS 条，带闪烁光标，不再挤在主屏里。
4. 状态指示都留着，而且会呼吸：右上角两颗真实 LED + 「已连接」「模型已接入」，灯芯明暗、外圈光晕、文字辉光都以 2.6 秒周期缓慢起伏，两颗错开相位（跟 App 里 StatusDot 同一节奏）；系统开启「减少动态效果」时全部静止。去掉轻/重拟物切换按钮（区别不大，切换收进窗口菜单／设置）。
5. 标题栏 / 输入区 / 黄铜挂杆 / 木板 仍全部严格等宽：；木板是深实木，间隙是后方窗口的高斯模糊（真 App 同款），避免抢刻字的注意力。
6. 木板上的字改成凿刻痕：凹槽上缘背光发暗、下缘受光亮、字色是刻开的浅木芯，边缘带烙焦，不再像浮在表面的亮字。
7. 标题只动字体：换成早期 Macintosh 那路衬线斜体（Hoefler Text / Apple Garamond），放大、拉字距、压印蚀刻在金属上；不加铭牌、不加框、不加铆钉。
