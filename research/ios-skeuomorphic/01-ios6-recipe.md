# iOS 6 拟物的五条规则

时间范围：iPhone OS 1（2007）到 iOS 6（2012）。顶点是 iOS 6，2012-10-29 Scott Forstall
离职、Jony Ive 接管人机界面，2013 年 iOS 7 全面转平。

## 1. 先选一件实物，再谈纹理

不是「给界面加皮革」，而是先决定这个 app 是**什么东西**，然后所有元素都必须属于它：

| App | 实物 |
|---|---|
| 日历 / 备忘录 | 皮革装订的日程本、黄色便签纸 |
| Game Center | 赌场绿毡牌桌（乔布斯亲自定的方向） |
| Podcasts | 开盘式磁带机 |
| Newsstand | 木书架 |
| Passbook | 皮质钱包，卡片塞在夹层里 |
| Find My Friends | 缝线皮革 |

判据：随便拿掉一个元素，如果它在现实里说不通，就不该出现。

## 2. 只用一个光源，永远在顶部偏中

这是整套界面「像真的」的第一性原理。所有控件共享同一个虚拟光源：

- 上缘有高光（specular），下缘有暗边（ambient occlusion）
- 凸起控件：外投影 + 顶部内高光
- 凹陷控件：顶部内阴影 + 底部反光
- 按压 = 高光翻转为内阴影 + 位移 1–2px + 整体变暗

光源一旦不统一，观感立刻变成「贴纸拼的」。

## 3. 材质分三层

1. **底材**：皮革、毛毡、木纹、拉丝金属、亚麻、纸张、玻璃
2. **结构**：缝线、铆钉、铜条、卡扣、包边、书架隔板
3. **表面**：油光、磨损、灰尘、指纹、反光渐变

本项目 `skeuo.html` 的木板 + 铜杆 + 麻绳正好对应这三层，可以直接沿用这个分层方式
去描述 iOS 端的新布局。

## 4. 状态即物理，不是透明度

| 状态 | 表现 |
|---|---|
| 可点 | 微凸，高光在上缘 |
| 按下 | 内阴影、下沉 1–2px、整体压暗 |
| 选中 | 物理上「翻到这一页 / 灯亮起」，不是加个蓝色边框 |
| 禁用 | 去饱和、去高光、不再反光 |
| 危险操作 | 红色 + 物理隐喻（撕纸、碎纸机） |

## 5. 声音与动效收尾

- 翻页（iBooks 的 page curl）、撕纸、卷帘（Passbook 删除时的碎纸机）
- 键盘咔哒、开关咔哒、发送成功的「嗖」
- 这些不是音效装饰，是「确认操作发生了」的物理反馈

## 附带：字体与配色

- 正文 Helvetica Neue（Light / Ultra Light 用于标签）
- 屏幕类元素用点阵/LCD 字体（本项目已用绿磷光屏 + SYS 液晶条）
- 配色服从材质本身：木=棕、毡=深绿、金属=灰、纸=米黄

## 教训（iOS 7 为什么能一刀切掉）

纹理是**烘进 @2x 位图**的，直接后果：

- 不能换主题、不能做深色模式
- 不能跟随动态字体缩放
- 新屏幕尺寸要重做一整套切图

现代复刻的正确做法：材质做成可替换的资产 + 参数（颜色、强度、光源角度），
不要写死在图片里。这条对 iOS 端尤其重要，因为手机一定会进深色模式。
