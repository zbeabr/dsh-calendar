> 本轮第一次拿到了真实渲染图：用 App 内置的 `--snapshot` 离屏导出了
> **全拟物**与 **Liquid Glass** 两种外观的窗口画面，并逐张肉眼核对
> （`dist/ui-skeuo-beta-realapp.png` 就是全拟物那张）。所以「长什么样」这一层

## 准备

- beta 5 已由 `cal-app/build.sh` 直接更新进 `~/Applications/DSH 日历.app`；确认关于面板显示 **1.3.0（17）**。
  （`dist/` 里的 1.3.0 dmg/zip 是 build 8 旧代码，不要拿来装。）
- 准备一个能看到**至少 2 条**日程的账号（或先用离线缓存造几条）。
- 再打开一个别的 App 窗口（备忘录 / 浏览器），放在日历窗口**后面**，用来看间隙的模糊效果。

**已知限制（不用当成 bug 报）**
- **跨应用点击穿透没有实现**：鼠标点在木板之间的空隙，事件仍由日历窗口接收，
  不会直接点到后面的窗口。`NSWindow.ignoresMouseEvents` 是整窗开关，单窗口架构下做不到
  「只让空隙穿透」；要靠全局鼠标监听动态切换，会引入点击竞态与拖动异常。
  要做干净得把木板拆成独立无边框窗口（属于重构）。beta 4 的间隙已改成模糊柔光背板，
  视觉上不再强调「能看见后面」，但穿透能力依旧没有。
- `DSH_CAL_FLAT=1` 调试模式下不画拟物机身（该模式本来就是朴素调试用）。
- 第 11–15、22–30、32、36 这些**交互与动画项**只做过静态渲染 + 编译 + 签名 + 启动，
  没有跑过真实点击，请逐项点过再下结论。

- 真实本地模型在不同权重下的输出稳定性（只跑过 `qwen3:8b` 几次调用）。
- macOS 深浅外观切换时，拉丝金属与木纹在暗色下的实际观感（离屏快照只跑了默认外观）。
