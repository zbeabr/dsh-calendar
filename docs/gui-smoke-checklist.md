# GUI 人工冒烟清单（1.3.0 beta 2 / build 9）

> **这份清单里的事我一项都没有亲手验证过。**
> 我能做且已经做的只有：`npm test` 全绿、`swiftc` 双架构编译通过、`make-release.sh` 自带校验、
> 包内文件逐字节比对、dmg 签名。AppKit 控件在真实窗口里怎么画、点了会怎样，
> 没有 GUI 会话就验证不了，也不能拿「编译通过」冒充「界面验证」。
> 请照下面逐项点一遍，把结果填进表格；没跑的就留空，不要预写「通过」。

## 准备

- 装 1.3.0 的 dmg/zip，用 `install.sh` 安装；确认关于面板显示 **1.3.0（8）**。
- 准备一个能看到**至少 2 条**日程的账号（或先用离线缓存造几条）。
- 再打开一个别的 App 窗口（备忘录 / 浏览器），放在日历窗口**后面**，用来看透明区。

**已知限制（不用当成 bug 报）**
- 透明区的**跨应用点击穿透没有实现**：鼠标点在木板之间的空隙，事件仍由日历窗口接收，
  不会直接点到后面的窗口。`NSWindow.ignoresMouseEvents` 是整窗开关，单窗口架构下做不到
  「只让空隙穿透」；要靠全局鼠标监听动态切换，会引入点击竞态与拖动异常，且本环境无法跑 GUI
  验证，所以本轮没有塞这个没验证过的 hack。要做干净得把木板拆成独立无边框窗口（属于重构）。
- `DSH_CAL_FLAT=1` 调试模式下透明区可能不生效（该模式本来就不画玻璃）。
- 上面的「删除 / 顺延 / 等宽 / 材质」**只做过编译验证，没有一项跑过真实 GUI**，
  请务必按 8–15 逐项点过再下结论。
