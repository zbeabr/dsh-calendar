# GUI 人工冒烟清单（1.3.0）

> **这份清单里的事我一项都没有亲手验证过。**
> 我能做且已经做的只有：`npm test` 全绿、`swiftc` 双架构编译通过、`make-release.sh` 自带校验、
> 包内文件逐字节比对、dmg 签名。AppKit 控件在真实窗口里怎么画、点了会怎样，
> 没有 GUI 会话就验证不了，也不能拿「编译通过」冒充「界面验证」。
> 请照下面逐项点一遍，把结果填进表格；没跑的就留空，不要预写「通过」。

## 准备

- 装 1.3.0 的 dmg/zip，用 `install.sh` 安装；确认关于面板显示 **1.3.0（8）**。
- 准备一个能看到**至少 2 条**日程的账号（或先用离线缓存造几条）。
- 再打开一个别的 App 窗口（备忘录 / 浏览器），放在日历窗口**后面**，用来看透明区。

## 一、无损切换（新增）

| # | 操作 | 期望 | 结果 |
|---|---|---|---|
| 1 | 在输入框敲一句没提交的话 → 窗口菜单「切换到轻拟物外观」 | 外观换掉，**那句话还在**、预览胶囊/冲突提示也还在 |  |
| 2 | 切换前后滚动列表到中间 | 滚动位置不跳回顶部 |  |
| 3 | 再点「切换到 Liquid Glass」 | 完全恢复玻璃外观，草稿仍在 |  |
| 4 | 退出 App 再打开 | 记住上次选的外观 |  |

## 二、轻拟物外观（新增）

| # | 检查点 | 期望 | 结果 |
|---|---|---|---|
| 5 | 绳子位置 | 两根绳从**输入框下沿**开始，输入框区域没有绳子、没有被遮住 |  |
| 6 | 木板之间的空隙 | 能看到后面那个窗口的内容（不是一块浅色面板） |  |
| 7 | 木板 = 一条日程 | 每条日程一块木板，时间/标题/日历色条可读 |  |
| 8 | 拖动窗口 | 木板带一点惯性轻摆，很快停下 |  |
| 9 | 系统「减少动态效果」打开 | 拖动时**完全不摆** |  |
| 10 | 深浅模式各看一次 | 木板文字在两种模式下都读得清 |  |

**已知限制（不用当成 bug 报）**
- 轻拟物模式下**没有删除/顺延按钮**，只有展示；要改日程请切回玻璃模式。
- 透明区的**跨应用点击穿透没有实现**：鼠标点在木板之间的空隙，事件仍由日历窗口接收，
  不会直接点到后面的窗口。要做到那一步需要按区域动态切 `ignoresMouseEvents`，风险高，留待后续。
- `DSH_CAL_FLAT=1` 调试模式下透明区可能不生效（该模式本来就不画玻璃）。
