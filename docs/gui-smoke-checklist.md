## 启动与基础

| # | 操作 | 期望 | 结果 |
|---|---|---|---|
| 1 | 冷启动 App | 3 秒内出窗口，无白屏闪烁；右上两颗 LED 中「已连接」为常亮/呼吸 | |
| 2 | 断网后启动 | 「已连接」转红，界面仍可输入（离线队列接管） | |

| 4 | `pkill -f "MacOS/DSHCalendar"` 后重开 | 新进程重跑启动逻辑（不是把旧窗口提到前台） | |
