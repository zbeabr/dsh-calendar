# 进行中（认领表）

> 多人 / 多模型同时改这个仓库时，**开工前先加一行**，完事删掉。
> 目的只有一个：同一时刻不要让两个人改同一个文件——git 事后区分不出谁写的，冲突合并会把一边的改动静默丢掉。

|---|---|---|---|---|---|
| _（当前无进行中任务）_ | | | | | |

## 规则

1. 一行一件事。改到别的文件就更新那一行的「改哪些文件」。
2. **`cal-app/App.swift` 同一时刻只能有一个人改。** 它是 4000+ 行、控件全自绘，两个人同时动必然冲突。
3. 并行时用独立 worktree + 独立分支，由一个人整合后跑全量 `npm run verify` 再推。
4. 收工删行；没做完但要让位，就在「状态」写 `让位：<下一步该做什么>`。

## 用法

```bash
git worktree add ../dsh-cal-<你的任务> -b feat/<任务名>
```

一个 worktree 一个分支，互不干扰；整合时在主工作区 `git merge`。前提是先把主工作区跑干净
（`npm run verify` 全绿 + `git status` 干净），否则第二个模型 clone 下来起点就是错的。
